Мои проекты 1.18

APK · Веб-версия

Проверка на телефоне по порядку

  1. Установи 1.18 поверх старой версии.
  2. У каждого из шести проектов должен быть короткий номер V… и кнопка APK. Сверь актуальную версию с сайтом проекта.
  3. Нажми APK: загрузка должна начаться через системный диспетчер Android, без открытия сайта. Проверь уведомление и файл в Загрузках (Android 10+). На Android 8–9 используется папка приложения. Установка не запускается автоматически.
  4. Нажми APK повторно во время загрузки: должна появиться подсказка, без второй загрузки. Повтори после успешного скачивания; затем удали файл и убедись, что его можно скачать заново.
  5. Проверь кнопку Друзьям под карточкой Мои проекты. Откроется публичная витрина пяти остальных приложений.
  6. На публичной витрине есть описание, версия, Сайт и, где доступна сборка, ПК. Нет карточки каталога, Codex и ссылок на репозитории.
  7. Проверь личную веб-версию owner.html?app=1: шесть проектов, версии, прямые APK и отдельная ссылка Друзьям только у каталога.
  8. Проверь все три вида списка с твоим масштабом Android, открытие сайтов, Codex, GitHub и запуск приложений.

На Android-устройстве эти шаги ещё нужно проверить. Автоматически проверены: сборка, пакет и версия APK, подпись предыдущего выпуска, SHA-256 и размер; веб-кнопки, шесть веток Codex, копирование, поиск и настройки, ширины 320/390/768; тесты механизма обновлений. Фактический запуск приложений, установка Android и обработка intent браузером требуют проверки на телефоне.
