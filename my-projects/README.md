# Мои проекты 1.5 — тестовый выпуск

Страница: https://nicolenkoe.github.io/fragment-logo-editor/my-projects/
Браузер: https://nicolenkoe.github.io/fragment-logo-editor/my-projects/?app=1
Версии: https://nicolenkoe.github.io/fragment-logo-editor/my-projects/#versions

## Обновления Android

Установить 1.5 вручную поверх 1.4 один раз. Подпись сохранена. Затем приложение проверяет releases.json при открытии (не чаще раза в минуту), не блокируя список сайтов. При более новой подходящей версии: «Обновить» / «Позже». «Позже» закрывает предложение; оно может появиться при следующем открытии приложения.

По умолчанию предлагаются стабильные версии. Под лупой есть ручная проверка и переключатель «Получать тестовые версии». Стабильных выпусков пока нет: 1.5 и предыдущая 1.4 помечены тестовыми до проверки на телефоне.

APK загружается только с HTTPS-адреса этого проекта, без GitHub-токена. До установки проверяются размер, SHA-256, имя пакета, увеличение versionCode и совпадение подписи с установленным приложением. Установщику передаётся временный доступ только к проверенному APK через закрытый ContentProvider. При первом обновлении Android может попросить разрешить установку из приложения. Установку всегда подтверждает пользователь.

Без интернета автоматическая проверка пропускается. Ошибки ручной проверки и загрузки отображаются; установленное приложение продолжает работать. Понижение версии, неизвестные каналы и withdrawn=true не предлагаются.

## Как опубликовать следующий выпуск

1. Изменить versionCode (строго увеличить), versionName и подпись версии в интерфейсе.
2. Собрать APK и подписать тем же закрытым ключом. Закрытый ключ не размещать в публичном репозитории.
3. Загрузить APK, затем в том же коммите обновить releases.json: versionCode, versionName, channel (stable/testing), notes, releasedAt, minSdk, minAndroid, apkUrl, sha256, sizeBytes, withdrawn.
4. apkUrl — только https://nicolenkoe.github.io/fragment-logo-editor/my-projects/my-projects-X.Y.apk без перенаправлений. Сам файл должен быть доступен одновременно с метаданными.
5. Для снятия проблемного выпуска поставить withdrawn=true; приложение не предлагает его. Автоматическое понижение версии не выполняется.
6. После проверки на телефоне сменить канал выпуска на stable. Автоматические проверки используют тот же JSON, что и список версий на сайте.

## Проверки

Компиляция Android, правила выбора обновления, допустимый адрес APK, формат SHA-256, подпись APK и совместимость сертификата; мобильная браузерная версия, фильтры версий и загрузки. Полный сценарий установки через Android на реальном телефоне пока не проверен.

## Ветка разработки

Пробная кнопка «Ветка Codex» добавлена только для проекта my-projects. Она открывает предоставленный владельцем адрес без изменения пути `/local/`:
https://chatgpt.com/local/6afbc15c-b5ac-8191-b689-765abe957078

Эта ссылка не делает переписку публичной: доступ определяется аккаунтом ChatGPT. Работа перехода внутри аккаунта и на телефоне требует проверки владельцем.

Объект projectThreads в releases.json позволяет добавлять проверенные ссылки других проектов без пересборки APK. Клиенты принимают HTTPS-ссылки chatgpt.com на local/c/codex/g. Пока привязана только одна ветка.
