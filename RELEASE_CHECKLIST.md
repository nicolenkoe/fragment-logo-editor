# Версия 1.2 — что проверить

1. Наложите большую надпись поверх маленькой, выберите нижнюю через список слоёв. Нажмите и перетащите внутри голубой рамки нижней: выбор должен сохраниться, верхняя надпись не должна перехватывать нажатие. Проверьте ручки размера и поворота.
2. Нажмите за пределами выбранной рамки, внутри другого объекта: выделение должно переключиться. Повторите с повёрнутой и растянутой надписью и у края рамки.
3. Проверьте явный выбор через список слоёв и Shift + щелчок для добавления другого объекта. Скрытый слой не должен перехватывать нажатия. Проверьте на компьютере и телефоне; редактор по-прежнему должен помещаться в окно.

4. Нажмите «Добавить картинку»: файл должен появиться отдельным объектом, не заменяя фото и существующие слои. Проверьте перенос, поворот, растяжение и отмену импорта. Можно выбрать несколько файлов.
5. В видео должны быть весь текущий интерфейс, видимый курсор и реальные изменения: чувствительность 35/70/100, перемещение, цвет, размер, группы и импорт картинки.

6. На стартовой странице проверьте кнопки «Редактировать в браузере», «Скачать APK для Android» и «Видеоинструкция». Редактор должен открываться по `editor.html`, APK — скачиваться, видео — показывать реальный текущий интерфейс с курсором и изменениями.

Короткое видео с русской озвучкой: https://logo-fragment-studio.devotedsesame.chatgpt.site/videos.html?video=checks

Логические тесты пройдены. В Chromium проверены 42 состояния на размерах 1440×900, 1280×720, 1024×768, 390×844, 375×667 и 844×390 — переполнение не обнаружено. Результаты: tests/evidence/layout-1.2.json. Стартовая страница также проверена на шести размерах: tests/evidence/landing-1.2.json. Установка APK на реальный телефон не проверялась.
