# 1.3.1 — проверки обновлений по порядку

1. Установить 1.3.1 поверх предыдущего APK. В «Проект → Проверить обновления» галочка «Только стабильные версии» изначально выключена. Текущий выпуск может показывать «Новых совместимых сборок нет», пока не опубликован следующий.
2. При доступном более новом совместимом APK оставить галочку выключенной: при запуске и возвращении из фона должна выбираться последняя опубликованная сборка, включая тестовую и экспериментальную. Загрузка начинается без нажатия «Обновить».
3. Включить «Только стабильные версии»: более новая тестовая/экспериментальная сборка не выбирается, скачивается последняя новая совместимая стабильная. Если стабильные есть, но все старее установленной, отката не будет. Если стабильных в списке совсем нет — показывается понятное сообщение.
4. Дождаться «APK скачан и проверен», нажать «Позже», свернуть и вернуть приложение несколько раз. Исправный APK должен повторно проверяться без новой загрузки; проверка списка не ограничивается сутками. При следующей новой разрешённой сборке загрузка начинается, несмотря на отсрочку старой установки.
5. После прерванной загрузки повторить проверку. Неполный файл не предлагается для установки; завершённый корректный временный файл восстанавливается без повторной загрузки. В тестах также проверены неверный размер/SHA-256, криптографическая порча, другая подпись, пакет и версия — установка недопустима.
6. Нажать «Обновить» для проверенного APK. Если Android просит разрешить установку из этого приложения — разрешить, затем подтвердить установку в системном окне. Отказ не удаляет редактор и проекты. Перед обновлением сохранить проект.

Оба режима, экспериментальные сборки, ограничения Android/ABI, идентичность пакета/версии, отсрочка только установки и повторные foreground-проверки проверены автотестами. Настоящий подписанный APK и изменённый APK проверены тем же криптографическим верификатором, который включён в приложение. Пройдены сценарии кэша и прерывания загрузки.

Установка/обновление на физическом Android и визуальная проверка недоступны в текущем окружении. Штатный браузер отсутствует; новое видео не записано. Редактор, инструменты, расположение элементов и остальные функции не менялись.
