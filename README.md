## Изменения в 1.2

Стартовая страница предлагает редактирование в браузере, скачивание Android APK и просмотр видеоинструкции. Редактор находится в `dist/editor.html`; Android-приложение открывает его напрямую. GitHub Pages настроен на ветку `gh-pages`, каталог `/`.

Нажатие внутри рамки уже выбранного объекта сохраняет его выбор даже под перекрывающим верхним слоем. Выйдите за рамку для выбора другого объекта; список слоёв и Shift-выбор работают независимо. Границы учитывают поворот, масштаб, растяжение и наклон.

Кнопка «Добавить картинку» создаёт отдельные слои поверх текущей композиции, не заменяя исходное фото. Можно выбрать несколько файлов. Картинки поддерживают все общие преобразования и объединение; одно нажатие отмены отменяет импорт всей партии.

## Возможности

Загрузка фото, цветной предпросмотр разделения и счётчик объектов, отдельные настройки детализации и цвета фона. Для встроенного логотипа чувствительность **35** создаёт четыре объекта: мотоцикл вместе с номером 123 и три слова. При **70** номер отделяется, а при **100** отделяются дополнительные внутренние детали. Перед разделением изображение остаётся целым; операция применяется кнопкой.

Модуль разделения содержит настройки сверху и кнопку применения снизу. Источник «Выбранный объект» позволяет повторно разделить только один слой: например, ENDURO на шесть букв с сохранением позиции, поворота, растяжения, цвета и остальных объектов. Предпросмотр остаётся на холсте; список справа содержит применённые слои.

Прямоугольное выделение и многоугольное лассо. Точки замыкаются двойным щелчком, Enter или кнопкой. Контур можно перемещать, независимо растягивать по ширине и высоте и вращать перед вырезанием. Фрагмент вырезается точно по контуру. Исходное место заполняется по окружающим цветам; при автоматическом разделении однотонный фон заполняется сразу.

Несколько объектов выбираются с Shift, галочками в слоях или рамкой «Выделить объекты». «Объединить» создаёт обратимую группу с общим перемещением, поворотом и масштабом. «Разобрать» сохраняет текущие координаты и преобразования.

Текстовые объекты поддерживают три семейства встроенных шрифтов, размер, жирное начертание, курсив и цвет. После создания текст перемещается, вращается и оформляется теми же инструментами. «Ещё → Редактировать текст» возвращает к редактированию букв и шрифта.

Ярко-голубая рамка выбранного объекта, маленькие угловые точки для пропорционального масштаба, боковые точки для независимого растяжения ширины/высоты и отдельная ручка поворота. Группы и текст поддерживают те же преобразования.

Масштаб, прозрачность, перекраска, удаление однотонного фона, копии, порядок слоёв и отмена действий. Экспорт PNG с прозрачностью и сохранение/открытие JSON-проекта со слоями, группами и текстом. Изображения посетителей обрабатываются в их браузерах, без отправки на сервер.

Редактор занимает одно окно. Длинные списки и настройки разбиваются на страницы; на телефоне панели открываются поверх холста. Подсказки появляются после секунды наведения. Видео записаны с реального интерфейса текущей версии: виден весь редактор, курсор, нажатия и изменения объектов. Есть быстрый старт, полный обзор и короткое видео проверки версии — с русской озвучкой, субтитрами и расшифровками.

## Локальный запуск и хостинг

Фронтенд не требует сборки или зависимостей:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте `http://localhost:8080`. На статический хостинг загружается содержимое `dist/`. Сеть не нужна для редактирования, после того как загрузились файлы приложения. Браузер может запрещать Worker при открытии HTML напрямую через `file://`; предусмотрен запасной вариант без Worker.

Обязательные проверки размеров окна закреплены в `AGENTS.md`; в браузере доступна функция `window.checkEditorLayout()`. Эти логические тесты не заменяют визуальную проверку интерфейса.

## Android

Исходники оболочки: `android/`. APK включает локальную копию редактора, шрифты, логотип и оба видео. Доступ к изображениям и сохранение результата выполняются через системные диалоги Android. Разрешение на интернет и общий доступ к хранилищу приложению не требуются. Минимальная версия — Android 6.0 (API 23).

Для сборки нужны Java Runtime, Android SDK Platform 35, Build Tools 35.0.0 и Eclipse ECJ 3.37.0. Скрипт `android/build-local.sh` принимает переменные `FRAGMENT_ANDROID_TOOLS` (каталог с `android-35`, `android-15` и `ecj.jar`), `FRAGMENT_ANDROID_BUILD` (временная сборка) и `FRAGMENT_ANDROID_KEYSTORE` (путь к сохраняемому ключу подписи). Ключи подписи не включены в репозиторий.

Шрифты DejaVu поставляются с лицензией в `dist/assets/fonts/LICENSE.txt`.

## Изменения в 1.2.4

Общая голубая рамка для нескольких выбранных объектов: восемь точек изменения размера и поворот. После объединения группа сохраняет те же органы управления. Растяжение и вращение применяются ко всем участникам; разбор группы сохраняет их преобразования.

Логические проверки пройдены. Браузерная проверка шести размеров и новое видео для 1.2.4 недоступны в текущем окружении; опубликованные видео относятся к 1.2.

Автоматическое разделение больше не требует выбора источника: сначала разделяется фото, затем выбранный объект. После применения нужно выбрать один объект для следующего разделения.

При изменении чувствительности рядом с ползунком сразу видно «Объектов: N». Сверьте число с цветными контурами до применения разделения.

Масштаб просмотра: колесо мыши на компьютере, два пальца на телефоне; процент над холстом возвращает вид по размеру окна. Средняя кнопка или пробел с перетаскиванием сдвигает просмотр. Размеры объектов и экспорт не меняются.

Контекстное меню: правая кнопка или удержание пальца 600 мс; копирование, вставка в место нажатия, дублирование, передний план, объединение/разбор и удаление. Внутри редактора работают Ctrl/Cmd+C и Ctrl/Cmd+V. Проверьте также отмену, меню у краёв экрана и отсутствие меню после щипка двумя пальцами.

В списке справа перетащите объект за ↕ выше или ниже: порядок наложения меняется, координаты сохраняются. Можно использовать стрелки клавиатуры на этой ручке. Чтобы перенести на другую страницу слоёв, задержите ручку над стрелкой следующей/предыдущей страницы.

## 1.3.0 — тестовый выпуск

Проверка обновлений с GitHub при запуске и вручную во вкладке «Проект». «Позже» откладывает предложение той же версии на 24 часа; ручная проверка действует сразу. Можно включить или отключить тестовые версии. На Android открывается скачивание APK с обычным подтверждением установки; браузер предлагает сохранить проект и перезагрузить страницу. История выпусков доступна на versions.html и в APK без интернета. Для установки механизма обновлений APK 1.2.4 нужно один раз заменить новым вручную.

## 1.3.1 — автоматическое скачивание проверенных обновлений

Проверка при запуске и каждом возвращении в Android-приложение, без суточного ограничения. По умолчанию разрешены стабильные, тестовые и экспериментальные выпуски. Галочка «Только стабильные версии» изначально выключена; её значение сохраняется. Сборка выбирается по времени публикации среди новых совместимых APK, без понижения установленного versionCode.

APK скачивается автоматически во внутреннее хранилище. Проверяются размер, SHA-256, настоящая криптографическая подпись APK, подпись установленного приложения, пакет, versionCode/versionName, минимальная версия Android и архитектуры. Корректный кэш повторно не скачивается, в том числе после сбоя перед переименованием временного файла. «Позже» откладывает предложение установки этой сборки на 24 часа, но не проверку списка и не скачивание новых разрешённых сборок. Установку из read-only content URI подтверждает Android.

Метаданные проверки — отдельный `downloads/<version>/update.json`, созданный после подписи APK. Это исключает попытку поместить SHA-256 APK внутрь самого APK. Сервер, API-ключи и отправка пользовательских изображений не нужны.

Проверки: `node tests/releases.cjs`, `node tests/updates.cjs`, `FRAGMENT_ANDROID_TOOLS=/path/to/tools bash tests/native-updates.sh`. Тесты включают настоящий подписанный и испорченный APK. Путь штатной проверки браузера недоступен; проверка на физическом телефоне ещё требуется.

## 1.3.2 — чувствительность, шрифты, дуга и палитра

Меню «Как разделять» удалено. Один ползунок задаёт вложенное разделение: на исходном логотипе 0 → 2 группы, 35 → 4 объекта, 70 → 5, 100 → 32 компонента. При увеличении значения количество не уменьшается; пиксели не отбрасываются. Для одного связного компонента отдельные части не выдумываются.

Каталог Google Fonts: 1961 открытое семейство на дату 2026-11-18, поиск и фильтр кириллицы. 12 дополнительных семейств встроены в APK, вместе с прежними тремя DejaVu доступны 15 семейств без сети. Tinos — бесплатная замена Times New Roman; системные Times New Roman, Arial и Courier New используются при доступности на устройстве. Остальные семейства загружаются через Google Fonts CSS2 при выборе; ключ API не нужен, текст и изображения в запрос не отправляются. Лицензии встроенных файлов находятся в assets/fonts/google. Для обновления каталога: scripts/prepare-fonts.py.

Текст изгибается от −180° до +180°, есть пресеты «Прямо», «Дуга», «Полукруг». После добавления сохраняет обычные операции объекта, редактирование текста и отмену. Личная палитра общая для текста и объектов, сохраняется на устройстве; оттенки явно добавляются и удаляются, вводятся HEX-кодом, длинная палитра разбита на страницы.

Логические проверки разделения, новых функций, реальных файлов шрифтов и кириллицы выполнены. Штатный браузер недоступен; визуальная проверка шести размеров окна и проверка Android на устройстве ещё требуются. Новое видео не записано.
