# Выпуск обновления

Источник проверки: публичный `gh-pages/versions.json` репозитория nicolenkoe/fragment-logo-editor. Сервер и ключи API не нужны. APK получает только список версий; изображения пользователя не отправляются.

1. Увеличить `versionCode` и версию в AndroidManifest.xml и `dist/release.js`. Добавить запись в `dist/versions.json` с датой, каналом `testing`/`stable`, изменениями и неизменяемыми ссылками `/downloads/<version>/fragment-editor.apk` и `fragment-source.zip`. Код версии уникален. Для новой функции сначала использовать testing.
2. Обновить `dist/release-catalog.js` из versions.json, чтобы история работала в APK без сети. Обновить версии ссылок на странице приветствия и в редакторе.
3. Выполнить тесты releases.cjs, updates.cjs и versions.cjs, проверки редактора и браузера по AGENTS.md. Собрать APK тем же приватным ключом, проверить подпись и все вложенные файлы.
4. Скопировать APK/ZIP в текущие downloads и в неизменяемый downloads/<version>; опубликовать source/main и сайт/gh-pages. Никогда не заменять файлы внутри каталога уже выпущенной версии.
5. Проверить свежий versions.json и ссылки. Установка поверх предыдущего APK и настоящий сценарий обновления проверяются на телефоне. Стабильным помечать выпуск после проверки, а не автоматически.

Редактор проверяет GitHub при запуске и по ручной команде. «Позже» откладывает только одну найденную версию на сутки; новая версия и ручная проверка не скрываются. Установка APK требует действия пользователя в Android. Без сети редактирование и сохранённая история доступны, обновления не выполняются. Браузерное обновление требует сохранения проекта перед перезагрузкой.
